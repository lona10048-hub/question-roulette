# 질문 룰렛 놀이 (2차시)

「질문하는 힘 기르기」 2차시용 모둠 웹앱이에요. 모둠마다 태블릿 한 대를 두고, 모둠원이 차례대로 태블릿을 넘기며 활동해요.

1. **① 질문 룰렛**: 차례인 친구가 **룰렛 돌리기**를 누르면 **질문 틀 룰렛**(12칸)과 **제시어 룰렛**(선생님이 정한 4~12칸)이 함께 돌아요. 나온 질문 틀과 제시어로 질문을 만들어 저장하고 태블릿을 넘겨요. 마음에 안 들면 차례마다 한 번 더 돌릴 수 있어요.
2. **잠시 멈춤**: 시간이 끝나면 선생님 화면에 모든 모둠 질문이 모여요. 선생님이 원할 때 다음 활동을 시작해요.
3. **② 한 마디 바꾸기**: 우리 모둠 질문을 하나 골라 딱 한 마디만 바꿔 새 질문을 만들어요. 바꾸는 방법 10가지는 학생 화면의 **TIP 카드**에 있어요.
4. **모아보기 · CSV**: 원래 질문 → 바꾼 질문이 짝지어 보이고, **질문 내려받기 (CSV)**로 두 질문을 모두 받아 3차시 프로그램에 올려요.

- **선생님은 준비할 것이 없어요.** 사이트에 들어가 게임 코드를 만들면 바로 수업할 수 있어요. 서버는 개발진이 운영해요.
- 화면은 **노트북과 태블릿**(가로·세로)에 맞춰 만들었어요. 휴대폰은 고려하지 않았어요.
- 빌드 도구 없이 동작하는 정적 웹사이트(HTML·CSS·JavaScript)예요. GitHub Pages에 올리면 바로 써요.
- 디자인(글꼴, 색, 고양이 궁금이, 버튼)은 1차시 「질문 기차 게임」과 같아요.

## 서버 하나를 모든 반이 함께 써요

| | |
| --- | --- |
| 서버 | 개발진이 Apps Script로 배포한 웹 앱 하나 (`js/config.js`의 `SERVER_URL`) |
| 선생님 구별 | 브라우저마다 만들어지는 선생님 열쇠. 게임은 만든 브라우저에서만 열고 지울 수 있어요 |
| 보관 기간 | 게임을 만든 뒤 **24시간**이 지나면 게임 코드와 질문이 모두 지워져요 → 끝나면 CSV로 저장 |
| 한도 | 선생님 한 분이 한꺼번에 가질 수 있는 게임 6개, 서버 전체 150개 |
| 이름 | 여러 학교가 함께 쓰는 서버라 모둠 친구 이름은 실명 대신 번호나 별명으로 쓰도록 안내해요 |

**연습 모드**: 선생님 화면 위쪽 "인터넷 없이 이 컴퓨터에서 연습해 보기"를 누르면, 인터넷 없이 이 컴퓨터의 여러 창에서 미리 해 볼 수 있어요. (같은 서버 코드 `gas/Code.gs`를 브라우저 안에서 돌려요)

## 활동 흐름과 화면

| 단계 | 선생님 화면 (전자칠판) | 모둠 태블릿 |
| --- | --- | --- |
| 준비 | 대주제(6가지 + 직접 입력), 제시어(예비 제시어 넣고 빼기 + 직접 쓰기), 활동별 시간, 모둠 수 | 코드 입력 → 모둠 고르기 → 친구 이름·차례 |
| 대기실 | 게임 코드·QR, 모둠 태블릿, 두 룰렛 미리 보기 | 두 룰렛 미리 보기, 놀이 방법 |
| ① 질문 룰렛 | 게임 규칙 · **질문 틀 12가지** · 제시어 · 남은 시간 · 태블릿 연결 (질문 내용은 보이지 않음) | 룰렛 돌리기 → 질문 쓰기 → 저장 → 다음 친구 |
| 잠시 멈춤 | 모둠별 룰렛 질문 모아보기, 별표·지우기, CSV, **한 마디 바꾸기 시작** 버튼 | 우리 모둠 질문, "선생님이 시작하면 넘어가요" |
| ② 한 마디 바꾸기 | 게임 규칙 · **바꾸기 방법 10가지** · 남은 시간 | 질문 고르기 → 한 마디 바꾸기 → 방법 고르기 → 저장 (TIP 카드) |
| 끝 | 원래 질문 → 바꾼 질문 짝지어 보기, CSV, 게임 정리 | 우리 모둠 질문 짝지어 보기 |

학생 태블릿은 질문을 저장할 때마다 서버로 보내고, 인터넷이 잠깐 끊기면 모아 두었다가 다시 보내요. 활동이 끝나면 "다 보냈어요" 표시를 남겨서 선생님 화면에 모둠별 **도착!**이 떠요.

## 3차시로 넘기는 CSV

선생님 화면의 **질문 내려받기 (CSV)** 파일(엑셀에서 바로 열려요, UTF-8 BOM)은 이 열로 되어 있어요. 3차시 프로그램은 이 열 이름으로 읽어요.

| 번호 | 모둠 | 활동 | 질문 | 질문 틀 | 제시어 | 원래 질문 번호 | 바꾼 방법 | 쓴 사람 | 별표 | 대주제 |
| --- | --- | --- | --- | --- | --- | --- | --- | --- | --- | --- |
| 1 | 1모둠 | 질문 룰렛 | 왜 급식실은 1층에 있을까? | 왜 ~할까? | 급식실 | | | 가온 | ★ | 학교 |
| 2 | 1모둠 | 한 마디 바꾸기 | 왜 급식실은 2층에 있을까? | | | 1 | 크기·수 바꾸기 | 나래 | | 학교 |

- **번호**는 파일 안에서 1부터 매긴 번호이고, **원래 질문 번호**는 그 번호를 가리켜요.
- **활동**은 `질문 룰렛` 또는 `한 마디 바꾸기`예요.

## 폴더 구성

```
index.html  teacher.html  student.html
css/app.css         1차시와 같은 디자인 + 2차시 룰렛 화면
js/config.js        서버 주소, 보관 시간, 서버에 묻는 간격
js/content.js       질문 틀 12개, 대주제 6개와 제시어, 한 마디 바꾸기 방법 10개
js/wheel.js         룰렛 그림과 돌리기 (매번 무작위, 두 화살표가 가운데를 바라봄)
js/api.js           서버 · 연습 모드와 이야기하기
js/r2api.js         2차시 기능 묶음
js/teacher.js       선생님 화면
js/student.js       모둠 태블릿 화면
gas/Code.gs         서버 코드 (1·2·3차시 함께, 버전 1.3.1) — 개발진이 배포
```

## 개발진이 할 일

1. **서버**: 2·3차시는 1차시와 따로 만든 **2·3차시 전용 서버**(구글 시트 「질문하는 힘 서버 (2·3차시)」, 코드 1.3.1)를 써요. 주소는 이미 `js/config.js`의 `SERVER_URL`에 들어 있어요. 1차시 서버는 건드리지 않아요.
   - 서버 코드를 고칠 때는 그 시트의 Apps Script에서 `Code.gs`를 바꿔 저장 → **배포 → 배포 관리 → 연필(수정) → 버전: 새 버전 → 배포**. ('새 배포'를 누르면 주소가 바뀌어요)
2. 서버 주소가 바뀌면 `js/config.js`의 `SERVER_URL` 한 줄만 고쳐요.
3. 보관 시간이나 한도를 바꾸려면 `gas/Code.gs`의 `TRIAL_TTL_MS`, `TRIAL_LIMIT`과 `js/config.js`의 `SERVER_RULES`를 같이 고쳐요.

## 시험해 본 것

- 서버 코드: 1차시 기능 31가지 + 2차시 기능(만들기·입장·저장·중복 저장 막기·단계 바꾸기·선생님 구별·24시간 정리)을 Node에서 시험
- 화면: 가짜 서버(여러 기기)와 연습 모드(여러 창)로 처음부터 CSV까지, 다른 선생님이 남의 게임을 보거나 열 수 없는지, 인터넷이 끊겼다 이어질 때, 새로고침해도 이어지는지, 노트북(1366×768, 1440×900)·태블릿(가로 1180×820, 세로 820×1180) 화면

실제 서버에 새 코드를 배포한 뒤 **태블릿 두 대로 한 번 해 보기**를 권해요.
